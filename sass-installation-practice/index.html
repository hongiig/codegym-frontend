🌸 SASS & SCSS Practice Guide

Báo cáo thực hành cài đặt môi trường, biên dịch SCSS sang CSS và quản lý SASS CLI / npm.

1. Kiểm tra Môi trường (Node.js, npm & SASS)

Môi trường đã được kiểm tra và kích hoạt thành công trên máy:

$ node -v => v24.21.0
$ npm -v => 11.19.0
$ sass -v => 1.105.0 (Dart Sass)
  • Node.js và npm đã sẵn sàng trong hệ thống.
  • SASS CLI hoạt động ổn định và hỗ trợ đầy đủ cú pháp SCSS hiện đại.

2. Các Lệnh Biên Dịch Đã Thực Hành

Biên dịch một tệp SCSS sang CSS:

sass scss/styles.scss css/styles.css

Kích hoạt chế độ theo dõi tự động (Watch Mode):

sass scss/styles.scss css/styles.css --watch

Biên dịch hàng loạt nhiều tệp từ thư mục scss/ sang css/:

sass scss/:css/ --watch

3. Các tính năng SCSS đã ứng dụng trong bài

  • SCSS Variables ($): Quản lý bảng màu, border-radius và font-family tập trung.
  • Nesting (Lồng nhau): Viết CSS có cấu trúc cây rõ ràng, dễ bảo trì.
  • Mixins (@mixin & @include): Tái sử dụng khối box-shadow và hiệu ứng chuyển động hover.
